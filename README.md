# ArchiveCleaner 📂

Высокопроизводительная утилита на C++, предназначенная для автоматического управления и очистки папок с архивами или данными путем сохранения только самых важных файлов за каждый месяц.

## 📝 Описание
В рабочих процессах архивирования часто требуется сохранять записи «начала месяца» и «конца месяца», в то время как промежуточные ежедневные бэкапы становятся избыточными со временем. **ArchiveCleaner** автоматизирует этот процесс. Программа сканирует указанные директории, группирует файлы по дате изменения (Год-Месяц) и оставляет ровно два файла для каждого месяца:
1. Самый ранний файл, найденный в этом месяце.
2. Самый поздний файл, найденный в этом месяце.

Все остальные файлы внутри этих месяцев удаляются автоматически.

## ✨ Ключевые особенности
* 🚀 Высокая производительность: Написано на нативном C++ для минимальной нагрузки на систему, что делает его идеальным для выполнения в планировщике задач сервера (Task Scheduler / Cron).
* 🛡️ Безопасный режим отладки: Запуск с флагом --debug позволяет сформировать список файлов, которые были бы удалены, не совершая фактического удаления.
* 📂 Гибкость настроек: Удобное управление несколькими путями через простой текстовый файл folders.txt.
* 📜 Подробное логирование: Каждый запуск создает уникальный лог-файл с временной меткой, содержащий отчет обо всех действиях (Оставлено, Удалено, Ошибка).
* ⚠️ Надежная обработка ошибок: Программа пропускает файлы, которые заняты другими процессами или к которым нет доступа, записывая ошибку в лог и продолжая работу.

## 🛠 Пример логики работы
Если в папке находятся файлы за июль:
- July_01_backup.zip
- July_02_backup.zip
- July_03_backup.zip
- July_04_backup.zip
- July_05_backup.zip
- July_06_backup.zip

ArchiveCleaner сделает следующее:
- Оставит: July_01_backup.zip (самый ранний) и July_06_backup.zip (самый поздний).
- Удалит: Все файлы с 2 по 5 число включительно.

## 🚀 Начало работы

### Предварительные требования
* Компилятор, поддерживающий стандарт C++17 или выше (MSVC, GCC или Clang).
* Для пользователей Windows: Visual Studio Community с установленным компонентом "Разработка классических приложений на C++".

### Сборка проекта
1. Клонируйте репозиторий:
git clone https://github.com/ВАШ_НИК/ArchiveCleaner.git
cd ArchiveCleaner

2. Скомпилируйте проект:

На Windows (через MSVC Developer Command Prompt):
cl /EHsc /std:c++17 main.cpp /Fe:ArchiveCleaner.exe

На Linux/macOS (используя GCC/Clang):
g++ -std=c++17 main.cpp -o ArchiveCleaner

### Конфигурация
Создайте файл folders.txt в той же директории, где находится исполняемый файл, и укажите в нем полные пути к папкам:
C:\Backups\Archive_01
D:\Data\Storage\OldLogs

## 🖥 Использование

### Режим отладки (Тестовый запуск)
Чтобы увидеть список файлов, которые будут удалены, не удаляя их физически, запустите программу с флагом -d или --debug:
ArchiveCleaner.exe --debug
# ИЛИ
ArchiveCleaner.exe -d
*После этого будет создан файл debug_delete_list.txt.*

### Рабочий режим (Удаление)
Для выполнения фактической очистки запустите программу без флагов:
ArchiveCleaner.exe

## 📊 Логирование
Каждый запуск создает новый лог-файл с именем вида log_YYYYMMDD_HHMMSS.txt. В логах отображаются:
- Успешные операции удаления каждого файла.
- Уведомления о файлах, которые были оставлены (KEEP).
- Подробные сообщения об ошибках, если папка недоступна или файл заблокирован.

## ⚠️ Дисклеймер
Используйте с осторожностью! Данная программа выполняет безвозвратное удаление файлов. Всегда запускайте программу в режиме --debug перед первым использованием, чтобы убедиться, что логика корректно обрабатывает ваши данные.
